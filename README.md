# AI-Based Legal Information Retrieval System (LHC IRS)

## 📖 Overview
This project is an **AI-based Information Retrieval System (IRS)** developed for searching and ranking **Lahore High Court (LHC) judgments**.  
The system processes **1000+ legal documents** and allows users to perform intelligent search queries using classical Information Retrieval techniques.

## 🎯 Objectives
- Build a searchable legal document repository
- Rank documents based on relevance
- Provide a professional web-based search interface

## 🔍 Features
- Text preprocessing and cleaning
- Inverted Index construction
- Boolean Retrieval (AND / OR / NOT)
- Phrase and Wildcard Search
- TF-IDF vectorization
- Cosine Similarity-based ranking
- Web interface to search, open, and download PDFs

## 🛠 Technologies Used
- Python
- Information Retrieval (IR)
- TF-IDF & Cosine Similarity
- Flask (Web Framework)
- HTML / CSS
- Pickle (Model persistence)

## 📂 Dataset
- **1000+ Lahore High Court judgments**
- Documents converted from PDF to text and preprocessed

## 🌐 Web Interface
- Search legal queries
- View ranked documents
- Open and download original PDF judgments
